<h1 align="center">MOS堆叠信号</h1>

<p align="center">MagicOS 11 双卡信号纵向堆叠 · LSPosed 模块</p>

## 功能

- 信号格、WiFi 各有「圆润」「方正」两种样式可选
- 可选 5GA 只显示 5A，可关闭 WiFi 替换

|  | 圆润（默认） | 方正 |
|:-:|:-:|:-:|
| 信号 | <img src="docs/signal_round.png" width="144"> | <img src="docs/signal_square.png" width="144"> |
| WiFi | <img src="docs/wifi_round.png" width="144"> | <img src="docs/wifi_square.png" width="144"> |

## 使用

1. 安装后在 LSPosed 中启用模块，作用域勾选「系统界面」
2. 软重启
3. 桌面「MOS堆叠信号」或 LSPosed 模块页进入设置

> 如果系统设置里有「信号堆叠」开关，请保持关闭。

在 MagicOS 11（Android 17）、荣耀 Magic9 Pro Max 上测试。
